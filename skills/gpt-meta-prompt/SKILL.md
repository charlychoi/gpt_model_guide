# 모델 추천을 포함하는 메타 프롬프팅

메타 프롬프팅은 AI에게 최종 작업 대신 그 작업에 사용할 지시문을 만들게 하는 기법이다. 짧은 요청을 실행 가능한 지시문으로 바꾸되, 사용자 의도를 바꾸거나 불필요하게 길게 만들지 않는다.

## 입력 해석

요청에서 **목표, 대상, 맥락, 입력 자료, 산출물, 제약, 완료 기준**을 추출한다. 이미 주어진 정보는 다시 묻지 않는다. 사소한 빈칸은 합리적 가정으로 표시하고 진행한다. 산출물 방향을 바꾸는 필수 정보만 최대 세 가지로 묻는다. 질문하면서도 알려진 내용으로 초안을 제공할 수 있다.

예시의 주제나 부서, 특정 제작 규칙을 모든 업무의 의무 조건으로 확장하지 않는다. 사용자가 요청하지 않은 기업명 금지, 125% 배율, 시간 제한 등을 일반 프롬프트에 자동으로 넣지 않는다. 모델 추천을 위해 원래 요청을 더 어려운 프로젝트로 바꾸지 않는다.

## 모델 배정

2026-10-08 기준 권장 출발점:
- 보통의 복합 제작·코딩·조사 정리·자동화: **GPT-6.1 Sol / Medium**.
- 모호한 목표, 어려운 설계, 상충하는 자료의 종합, 중요한 내용 검토: **GPT-6 Astra / Medium~High**. 짧은 글의 사실·뉘앙스 보존 수정에는 Low도 고려한다.
- 확정된 규칙에 따른 분류·추출·반복 가공: **GPT-6 Luna / Low~Medium**, 대표 입력을 먼저 검증한다.
- 전체 프로젝트가 단순하면 모델 하나만 추천한다. High 이상을 무조건 적용하지 않는다. 실제 제공 모델과 옵션이 다르면 사용 가능한 대안을 제시한다.

최신성·가격·기능이 선택을 좌우하면 [공식 모델 선택 문서](https://developers.openai.com/api/docs/guides/model-selection)와 [모델 목록](https://developers.openai.com/api/docs/models)을 확인한다. 확인하지 못하면 현재 확인된 사실처럼 말하지 않는다. 추천은 모델을 자동 전환하거나 하위 에이전트를 실행했다는 뜻이 아니다.

## 출력

1. **요청 이해와 가정**: 짧게 정리한다. 미정 사항은 가정 또는 확인 필요로 구분한다.
2. **추천 모델**: 단일 작업이면 한 줄, 복합 작업이면 `단계 / 모델 / 추론 강도 / 이유` 표. 배정은 제안이며 사용자가 변경할 수 있다.
3. **복사용 실행 지시문**: 단일 작업은 한 개, 독립 인수인계가 필요한 프로젝트만 여러 개로 제공한다. 각 지시문에 추천 모델·추론 강도를 표시한다. 각 블록은 관련 맥락과 입력 위치를 포함해 혼자서도 실행 가능해야 한다.

실행 지시문에는 작업에 필요한 범위에서 다음을 넣는다:
- 목표와 결과를 사용할 대상.
- 제공된 맥락·입력 자료·미정 사항.
- 산출물의 내용·형식과 서로의 연결 관계.
- 지켜야 할 제약, 모델이 스스로 정할 수 있는 범위, 실제 외부 실행이 있는 경우의 승인 경계.
- 완료 기준과 결과물에 맞는 검수 방법.
- 실제로 확인한 것, 미확인 사항, 남은 작업을 짧게 보고하도록 하는 마무리.

사소한 편집마다 승인받으라는 규칙을 넣지 않는다. 반대로 게시·메시지 전송·유료 구매 등의 권한을 지시문 생성만으로 부여하지 않는다. 외부 실행이 없는 글쓰기에는 불필요한 승인 항목을 만들지 않는다.

## 검수

- 원래 요청의 핵심 산출물이 모두 포함되었는가?
- 창작된 숫자·환경·제품 기능이 사실처럼 들어가지 않았는가?
- 설명·슬라이드·실행 결과처럼 연결되어야 할 자료가 일치하는가?
- 결과만 보여주고 실제 조작 과정을 했다고 꾸미도록 지시하지 않았는가?
- 시험·청취·렌더 확인 없이 품질 합격을 선언하도록 하지 않았는가?
- 결과물에 비해 지시가 불필요하게 길지 않은가?

영상 요청에서는 실제 도구·입력·클릭·실행·결과·스크롤을 보여주는 시연과 음성·화면 동기화 검수를 포함한다. 영상 길이·해상도·음성·브라우저 등 사용자가 정하지 않은 사항은 가정으로 명시한다. 텍스트 모델이 TTS나 녹화 도구를 대신한다고 설명하지 않는다.

일반 AI 채팅창은 GitHub 스킬을 자동으로 로드하지 않을 수 있다. 그 경우 스킬 내용을 붙여 넣거나 함께 제공된 `prompts/chat-meta-prompt.md`를 사용한다. 파일 업로드·프로젝트 지침은 해당 서비스가 지원할 때만 안내한다.
