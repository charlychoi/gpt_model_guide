# 메타 프롬프팅 예시: 헤르메스 초보자 강의

## 사용자의 짧은 요청

> AI agent 헤르메스 관련해서 초보자들 대상으로 강의를 하려고 강의 교안 원고, 실습 시연 영상을 생성해줘.

## 지시문 생성 시의 해석

목표는 헤르메스 에이전트를 처음 접하는 사람이 원리와 기본 사용법을 이해하고 한 가지 업무를 직접 실행하는 강의다. 여기서는 헤르메스를 **Hermes Agent**로 가정한다. 다른 제품을 뜻하면 먼저 바로잡는다. 강의 길이·버전·실행 환경은 미정이므로 실제 제작 전 확인한다. 아래 예시의 강의 길이는 사용자 요구가 아니라 **이론 5분 + 실습 약 10분이라는 제안**이다.

| 단계 | 추천 모델 | 추론 강도 | 이유 |
|---|---|---|---|
| 교육 목표·쉬운 예시·시나리오 설계 | GPT-6 Astra | High | 초보자에게 필요한 범위와 개념의 연결 결정 |
| 교안·슬라이드·실제 시연 제작 | GPT-6.1 Sol | Medium | 여러 산출물의 일치와 실제 도구 실행 |
| 문장·파일 목록 등 반복 가공 | GPT-6 Luna | Low~Medium | 확정 규칙에 따른 처리; 선택 단계 |
| 내용·시연 일치 최종 검토 | GPT-6 Astra | Medium | 개념 오류와 초보자 관점의 흐름 검토 |

## 1. 강의 설계용 실행 지시문

**추천 모델: GPT-6 Astra · High**

Hermes Agent를 처음 사용하는 사람을 위한 강의를 설계해 주세요. 목표는 수강자가 AI 에이전트와 일반 채팅의 차이를 이해하고, 헤르메스에게 작은 업무 하나를 맡겨 결과를 확인하는 것입니다.

우선 제공된 공식 문서와 설치 환경에서 제품·버전·기능을 확인하세요. 입력이 없으면 필요한 자료를 알려 주고, 확인하지 못한 설치 명령이나 화면을 만들어내지 마세요. 이론 5분과 실습 약 10분은 제안이며 실제 길이는 확정해야 합니다.

실습 예시는 초보자가 따라 하기 쉬운 하나를 골라 주세요. 예를 들어 제공된 메모를 읽고 할 일 목록을 만드는 업무를 고려하되 실제 환경에서 가능한지 확인하세요. 처음부터 여러 외부 서비스와 계정을 연결하는 과제로 넓히지 마세요.

교육 목표, 이론의 핵심 개념, 실습의 입력·동작·기대 결과, 필요한 자료, 제작 단계별 완료 기준을 작성하세요. 이론은 개념을 설명하고 실습은 그 개념을 실제 행동으로 이어 가도록 구성하세요. 제공된 환경에서 실제 할 수 있는지와 초보자가 이해할 수 있는지 점검해 주세요.

입력: `[Hermes 공식 문서, 설치 버전, 실행 환경, 확정한 강의 길이]`

## 2. 교안·슬라이드·실습 영상 제작용 실행 지시문

**추천 모델: GPT-6.1 Sol · Medium**

아래 확정된 강의 설계를 바탕으로 Hermes Agent 초보자 강의의 낭독 원고, 보조 슬라이드, 실습 시연 영상을 제작해 주세요.

원고는 쉽게 들리는 짧은 문장으로 쓰고, 처음 나오는 용어만 간략히 설명하세요. 이론을 실습에서 다시 길게 반복하지 마세요. 실습 원고에는 보여줄 화면, 입력할 지시문, 클릭·실행·결과 확인 위치와 보조 슬라이드 표시 위치를 넣으세요. 입력 지시문은 학습자가 복사해 사용할 수 있는 형태로 따로 제공하세요.

화면 시연은 실제 실행으로 진행하세요. 입력하는 과정, 보내기 또는 실행 동작, 처리 과정, 결과와 필요한 스크롤을 보여 주세요. 결과 화면만 갑자기 나타나게 하지 마세요. 실제 결과가 예상과 다르면 결과를 기준으로 설명을 수정하세요. 마우스 포인터와 내레이션이 가리키는 위치를 일치시키세요.

음성·녹화·편집 도구는 사용 가능한 환경과 사용자 선호로 선택하세요. 목소리, 배속, 화면 해상도, 녹화 범위 등 미정 설정은 합리적 초안을 제안하되 가정으로 표시하세요. 계정·비밀 정보는 결과물에 노출되지 않도록 확인하세요. 제작을 위해 요청되지 않은 개인정보 업로드, 유료 구매, 외부 게시를 진행하지 마세요.

완료 기준은 다음과 같습니다. 원고·슬라이드·실제 시연이 같은 절차와 결과를 설명해야 합니다. 슬라이드는 읽을 수 있고 필요한 경우 편집 가능해야 합니다. 음성은 실제로 검사하여 첫·끝 음절 끊김과 잡음을 확인하고 화면과 동기화해야 합니다. 실행하지 않은 과정이나 검사하지 않은 품질을 완료로 보고하지 마세요.

먼저 짧은 시연·음성 샘플로 설정을 확인한 뒤 전체 결과물을 제작하고, 확인한 검수 결과와 남은 사항을 보고하세요. 샘플의 사용자 승인 대기 여부는 사용자가 정한 제작 흐름에 따르세요.

입력: `[확정 설계, 공식 자료, 실제 실행 환경, 사용자 제작 설정]`

## 3. 반복 가공용 실행 지시문 — 필요한 경우만

**추천 모델: GPT-6 Luna · Low~Medium**

아래 확정된 원고를 내용 수정 없이 문장별 목록으로 정리해 주세요. 문장 ID, 원문, 해당 슬라이드 번호를 표로 작성하세요. 슬라이드가 정해지지 않은 문장은 미정으로 표시하세요. 문장을 임의로 생략하거나 고치지 마세요. 원본과 비교해 누락·중복·순서 변경이 없는지 확인하세요.

입력: `[확정 원고와 슬라이드 대응 정보]`

## 4. 최종 검토용 실행 지시문

**추천 모델: GPT-6 Astra · Medium**

제공한 Hermes Agent 강의 원고·슬라이드·시연 기록을 초보자 관점에서 검토해 주세요. 공식 자료와 실제 실행 결과를 기준으로 기능 설명의 정확성, 이론에서 실습으로의 연결, 불필요한 반복, 학습자가 따라 할 수 있는지 확인하세요. 직접 확인하지 못한 영상·음성 품질은 미확인으로 남기세요. 수정이 필요한 위치와 이유를 짧게 제시하고, 필요한 부분만 수정하세요.

입력: `[완성 원고, 슬라이드, 시연 영상 또는 검토 가능한 화면·기록, 공식 자료]`
